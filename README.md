# 🚗 FuelFinder – Smart Fuel Station Locator

FuelFinder is a location-based web application that helps users find the most suitable fuel stations based on their needs. It combines interactive maps with smart filtering to improve travel efficiency and decision-making.

## 🚀 Features

- 📍 Location-based fuel station search  
- 🔍 Manual location input  
- ⚡ Filters:
  - EV Charging  
  - Food availability  
  - Toilets  
  - 24/7 Open  
- 🗺️ Interactive map interface  
- 🎯 Smart station selection based on user preferences  
- 🖱️ Add new stations via map interaction  

---

## 🧠 Problem It Solves

Finding the right fuel station is often inefficient:
- No proper filtering for amenities  
- Time wasted searching manually  
- Lack of user-focused selection  

FuelFinder solves this by providing **fast and filtered results based on user needs**.

---

## 🏗️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Maps:** Leaflet.js + OpenStreetMap
